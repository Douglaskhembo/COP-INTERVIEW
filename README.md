## How to run

1. Clone repo and open the pom.xml file of the cloned folder in your intellij or preferred IDE
2. Create dabase and change database mappings in application.yml in resources folder
3. Run the project using Run button at the top of the intellij (green in color)
4. Expose your port 8088 on ngrok using command (ngrok http 8088)
